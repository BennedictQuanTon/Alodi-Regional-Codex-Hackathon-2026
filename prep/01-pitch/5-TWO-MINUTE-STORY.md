# 5 · The two-minute story

The script of the demo film, `video/alodi-story.mp4` (2:05). Path A carries the story; the other paths get one line each. The film is on the landing page and on slide 8 of the deck.

Cast: Tuan, the shipper. Minh, the buyer. Minh's parcel, a 6L air fryer.

| Time | Voice | Line |
| --- | --- | --- |
| 0:01 | Narrator | It’s 10:02. Minh is in a meeting. And the phone? On silent. |
| 0:07 | Narrator | At the door, Tuan is waiting, air fryer in hand. One call. Two calls… Nothing. |
| 0:14 | Narrator | Seventeen more stops are waiting. So the parcel goes back on the bike. And all that’s left is two sad little words: No answer. |
| 0:24 | Narrator | We’ve all been Minh. And we’ve all felt a little bad for Tuan. |
| 0:31 | Narrator | So we built Alodi. An AI agent that rescues failed deliveries, so the second try actually lands. |
| 0:39 | Narrator | Here’s how it works. Tuan taps one button. No typing. No calling back. And off to the next stop. |
| 0:46 | Narrator | From here, Alodi takes over. First, a friendly message to Minh, right away. |
| 0:53 | Narrator | An hour later? Still quiet. So Alodi does something lovely. It picks up the phone. |
| 1:00 | Alodi | “Hi Minh! This is Alodi, your delivery assistant. This call is recorded. When’s a good time?” |
| 1:07 | Minh | “Oh, sorry! Tomorrow after five, please. Leave it with security in Tower B. Or call my wife.” |
| 1:14 | Narrator | Did you catch all that? Alodi did. When. Where. Who. All in one neat little card. |
| 1:20 | Narrator | It checks the rules, then sends the card straight to the next shipper’s phone. |
| 1:25 | Narrator | And the next evening? No calls. No guessing. Just… delivered. |
| 1:30 | Narrator | Minh gets the parcel. The shipper saves a trip. The seller keeps the sale. |
| 1:36 | Narrator | Already agreed a new time at the door? Tuan holds the button and says it, in ten seconds. Alodi writes the same card. |
| 1:45 | Narrator | And when an answer isn’t clear, or a buyer says no? Alodi stops, and asks a person. Because some calls should stay human. |
| 1:54 | Narrator | Meanwhile, the hub sees every rescue, live, on one dashboard. |
| 1:59 | Narrator | Alodi. Make the second drop land. |
